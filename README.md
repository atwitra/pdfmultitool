# ⚡ Smart PDF Suite - All-in-One Offline PDF Tools by Atwitraaa

Aplikasi Desktop Windows native yang me-reverse engineer seluruh fungsionalitas populer dari **iLovePDF** dan menjadikannya **100% Offline**, cepat, tanpa batas ukuran file, dan tanpa perlu upload berkas ke server pihak ketiga (privasi terjaga penuh).

---

## 🛠️ Fitur & Modul Lengkap

### 1. 🏷️ Smart Renamer (Fitur Khusus Berbasis Konten)
- Ekstraksi otomatis nama siswa, kelas, NISN, atau teks label kustom dari dalam dokumen PDF.
- Format penamaan fleksibel: `{nama}.pdf`, `{nomor_urut} - {nama}.pdf`, `{kelas} - {nama}.pdf`.
- Pratinjau interaktif, deteksi duplikat, dan fitur **Undo**.

### 2. 📑 Gabung & Pisah (Merge & Split)
- **Merge PDF**: Gabungkan puluhan file PDF menjadi satu berkas dengan urutan yang bisa digeser naik-turun.
- **Split PDF**: 
  - Pecah setiap halaman jadi berkas PDF mandiri (1 Halaman = 1 File).
  - Ekstrak rentang halaman tertentu (misal: `1-3, 5, 8-10`).

### 3. ✂️ Halaman & Rotasi (Pages & Rotate)
- **Remove Pages**: Hapus halaman yang tidak diinginkan dengan mudah (misal: `2, 4-6`).
- **Rotate PDF**: Putar orientasi halaman dokumen `90°`, `180°`, atau `270°` (bisa seluruh halaman atau halaman tertentu saja).

### 4. 🔄 Konversi & Kompresi (Convert & Compress)
- **JPG/PNG to PDF**: Gabung banyak foto / scan gambar ke satu dokumen PDF utuh.
- **PDF to Markdown / Teks**: Ekstrak teks halaman per halaman menjadi format `.md` atau `.txt` (cocok untuk catatan atau prompt AI).
- **Compress PDF**: Kompresi stream Flate lossless untuk mengecilkan ukuran berkas tanpa merusak kualitas teks.

### 5. 🛡️ Keamanan & Watermark (Security & Watermark)
- **Protect PDF**: Kunci dokumen PDF dengan enkripsi password.
- **Unlock PDF**: Buka proteksi password dokumen dan simpan versi bebas password.
- **Add Watermark**: Tambahkan teks cap air (misal: `CONFIDENTIAL`, `DRAFT`, `RAHASIA`) dengan posisi diagonal transparan.
- **Add Page Numbers**: Tambahkan nomor halaman otomatis di bagian bawah tengah (`Halaman {n} dari {total}`).
